# Teikore – KI-Modelle

Dieses Repository enthält nur Modelldateien, die Teikore bei Bedarf herunterlädt (Einstellungen → Modelle). Kein Programmcode.

| Datei | Herkunft | Lizenz |
|---|---|---|
| `sam2.1_hiera_base_plus_encoder.onnx`, `sam2.1_hiera_base_plus_decoder.onnx` | SAM 2.1 base-plus (Meta, https://github.com/facebookresearch/sam2), nach ONNX umgewandelt | Apache 2.0 (`SAM2-LICENSE-Apache-2.0.txt`) |
| `BiRefNet_HR-matting-epoch_135_fp16.onnx` | BiRefNet HR-matting (https://github.com/ZhengPeng7/BiRefNet), nach ONNX fp16 umgewandelt | MIT (`BiRefNet-LICENSE-MIT.txt`) |
| `german-sentiment-bert*.onnx/.txt/.json` | german-sentiment-bert (Oliver Guhr, https://huggingface.co/oliverguhr/german-sentiment-bert), nach ONNX umgewandelt | MIT (`german-sentiment-bert-LICENSE-MIT-full.txt`) |

Die Modelle wurden nicht verändert, nur in das ONNX-Format umgewandelt. Alle Rechte an den Modellen liegen bei ihren Urhebern.
